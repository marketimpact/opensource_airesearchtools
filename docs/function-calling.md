# Gemma 4 Function Calling

## Tool Definition Methods

### JSON Schema Format
```json
{
  "type": "function",
  "function": {
    "name": "function_name",
    "description": "Description of what the function does",
    "parameters": {
      "type": "object",
      "properties": {
        "param_name": {
          "type": "string",
          "description": "Parameter description"
        }
      },
      "required": ["param_name"]
    }
  }
}
```

### Python Functions
Pass raw Python functions with type hints and docstrings (Google Python Style Guide). The system automatically generates JSON schema by parsing function signatures.

## Tool Passing

Tools are passed via `processor.apply_chat_template()` using the `tools` parameter:
```python
text = processor.apply_chat_template(message, tools=[tool_schema], 
                                     tokenize=False, add_generation_prompt=True)
```

## Function Call Syntax

The model generates function calls in this format:
```
<|tool_call>call:function_name{param:<|"|>value<|"|>}<tool_call|>
```

## Tool Response Format

Append tool execution results to message history using:
```python
{
  "role": "assistant",
  "tool_calls": [{"function": {"name": "function_name", 
                               "arguments": {"key": "value"}}}],
  "tool_responses": [{"name": "function_name", 
                      "response": function_result}]
}
```

For multiple tools:
```python
"tool_responses": [
  {"name": "function_name_1", "response": result_1},
  {"name": "function_name_2", "response": result_2}
]
```

## Thinking Mode

Enable enhanced reasoning with: `enable_thinking=True` in `apply_chat_template()`.

## Best Practices

1. **Always validate** function names and arguments before execution
2. **Never execute** code generated by the model without safeguards
3. **For complex parameters:** Use manual JSON schemas rather than automatic conversion
4. **Tool response format:** Use the specific structure above so the chat template generates required token structures
5. Manually define schemas for custom objects with nested properties
